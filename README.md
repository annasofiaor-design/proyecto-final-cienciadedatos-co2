##  Descripción del proyecto
Desarrollo de un flujo completo de Ciencia de Datos basado en el artículo y los datos abiertos de **Our World in Data** (`CO₂ emissions`). El proyecto incluye la limpieza de datos históricos, análisis exploratorio mediante visualizaciones, y un modelo de **Regresión Lineal** para estudiar la tendencia de crecimiento de las emisiones.

## Herramientas
* **Lenguaje:** Python (Google Colab / Jupyter Notebook)
* **Librerías:** Pandas, NumPy, Matplotlib, Seaborn, Scikit-Learn
